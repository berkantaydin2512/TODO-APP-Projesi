# Web Geliştirme TO DO App Projesi

Bu proje, ReactJS (ESLint) ve Vite kullanarak geliştirilmiş bir Todo List uygulamasıdır. Ayrıca, basit bir Node.js sunucusu ile backend desteği sağlar.

## Kurulum ve Çalıştırma

### Ön Gereksinimler

- Node.js (versiyon 14 veya üzeri)
- npm

### Adımlar

1. **Proje bağımlılıklarını yükleyin:**

```bash
npm install
```

2. **React.js bağımlılıklarını indirme:**

```bash
npm create vite@latest my-app -- --template react-ts
```

3. **Paketleri onaylama:**

```bash
- Ok to proceed? (y)
- y
```

4. **Linter seçme:**

```bash
- Which linter to use?
- ESLint
```

5. **Npm' i başlatma ve indirme:**

```bash
- Install with npm and start now?
- Yes
```

\*. **Geliştirme sunucusunu tekrar başlatma (eğer sunucu kapnamışsa tekrar çalıştırmak için)**

```bash
npm run dev
```

Artık uygulamanız http://localhost:5173 adresinde çalışıyor olmalı!
